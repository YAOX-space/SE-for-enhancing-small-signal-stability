# Full Reproduction Notes

This folder documents the reproduction package for:

Yuan et al., "Placing Storage Energies for Enhancing Small-Signal Stability of Converter-Based-Renewable Systems", IEEE TIA, 2025.

## How To Run

Open MATLAB, navigate to the `matlab/` subdirectory of this repository, then
run:

```matlab
run_physics_simulink_reproduction
```

The script locates its own directory via `fileparts(mfilename('fullpath'))` and
writes all outputs relative to that path.  No hardcoded paths need to be
changed.

## Comparison With The Paper

Matched exactly or numerically:

- Two-area four-CBR initial largest positive eigenvalue:
  - paper: `lambda_max^+ = 0.376`
  - reproduction: `0.376011`
- Two-area four-CBR storage placement:
  - paper: nodes `[1, 4]`
  - reproduction: nodes `[1, 4]`
  - Table I/II validation gives first node `1` and second node `4`; Table III exhaustive gSCR validation gives optimum `[1, 4]`.
- 39-node proposed placement:
  - paper: nodes `[37, 38, 39]`
  - reproduction report uses `[37, 38, 39]`
  - Table IV/XII/XIII validation from the supplied images gives `39 -> 38 -> 37`.
- 33-converter first placement:
  - paper: node `67`
  - The greedy algorithm (`greedy_se_passive` in `run_physics_simulink_reproduction.m`)
    computes directly from the Z matrix and independently selects node `67` as the
    first placement, matching the paper.
  - Cross-validation caveat: Table VIII sensitivity values are truncated to 4 decimal
    places, giving tied minima `[45, 56, 67]` at `-0.0122`.  The tie cannot be broken
    from Table VIII alone; the unrounded author data disambiguates.  The greedy
    algorithm avoids this issue because it evaluates actual gSCR values (not truncated
    sensitivities) and produces a unique ranking.
- 33-converter network source:
  - Reference [20] Appendix B Table B.II has now been transcribed. The derived
    collector-line reactance is `0.000130286 p.u.` for each adjacent 35 kV line
    segment using the paper's base values.
  - The imported edge list has 67 branches over 68 buses. Grounding the infinite bus
    gives a 67-by-67 network matrix with condition number about `4397.89`.
- 33-converter proposed placement:
  - paper: nodes `[42, 43, 44, 45, 53, 54, 55, 56, 65, 66, 67]`
  - independently computed by `greedy_se_passive` from the Z matrix; result matches
    the paper's reported placement.
- Reported gSCR values are preserved for the 39-node and 33-converter comparison cases.

Reproduced qualitatively (trend illustration, not EMT-identical waveforms):

- Fig. 6, Fig. 11, Fig. 12, and Fig. 14 time-domain responses are generated by
  `build_gfl_state_space.m`, a modal reduced-order state-space model calibrated to
  Table V eigenvalue data (four (gSCR, σ, ω) points from the paper).  The dominant
  poles are obtained by pchip interpolation of those data points, **not** from a
  first-principles GFL converter model.  Consequently:
  - The qualitative stability trend is faithfully reproduced (lower gSCR → weaker
    damping; optimal SE placement → fastest convergence).
  - The waveforms cannot be used to independently verify the paper's stability
    conclusions — the model was calibrated to those conclusions.
  - The curves are not equivalent to the authors' EMT simulations (which include
    full current-loop dynamics, LCL filter, voltage feedforward filter 1/(1+0.01s),
    limiters, and dq initialization).
- The gap between the first-principles PLL model (dominant mode −13 ± 87.5i) and
  the paper's Table V values (+0.09 ± 88.3i) is caused by the voltage feedforward
  filter (Table IX), which introduces ~41° phase lag at 88 rad/s and creates
  strong current–network coupling that a quasi-static network model cannot capture.
- The authors' original EMT/Simulink model is not provided in the PDF. Exact EMT
  matching requires unpublished implementation details: limiters, initialization,
  and dq sign conventions.

## Implementation Scope

The implemented scripts cover all numerical experiment sections in the paper:

- Single-converter infinite-bus eigenvalue trend, corresponding to Fig. 8.
- Modified IEEE 39-node gSCR/eigenvalue assessment, corresponding to Fig. 10 and Fig. 11.
- Modified IEEE 39-node SE placement comparison, corresponding to Table V and Fig. 12.
- 33-converter SE placement comparison, corresponding to Table VIII and Fig. 14.
- Two-area four-CBR illustrative placement, corresponding to Table I-III and Fig. 6.

## Important Limitation

This is now a data-backed reproduction of the paper's **gSCR method, placement logic, reported placements, reported stability ordering, scalar metrics, and imported network tables**. It is not a bit-for-bit reconstruction of the unpublished EMT model. To obtain EMT-identical waveforms, the remaining missing implementation details would be controller limiters, exact dq sign conventions, initialization procedure, and the authors' original Simulink/EMT block choices.
