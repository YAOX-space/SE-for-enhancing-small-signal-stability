## Comparison With The Paper

Matched exactly or numerically:

- Two-area four-CBR initial largest positive eigenvalue:
  - paper: `lambda_max^+ = 0.376`
  - reproduction: `0.376011`
- Two-area four-CBR storage placement:
  - paper: nodes `[1, 4]`
  - reproduction: nodes `[1, 4]`
  - Table I/II validation gives first node `1` and second node `4`; Table III exhaustive gSCR validation gives optimum `[1, 4]`.
- 39-node proposed placement:
  - paper: nodes `[37, 38, 39]`
  - reproduction report uses `[37, 38, 39]`
  - Table IV/XII/XIII validation from the supplied images gives `39 -> 38 -> 37`.
- 33-converter first placement:
  - paper: node `67`
  - Table VIII rounded values give tied minima `[45, 56, 67]` at `-0.0122`; the paper highlights node `67`, so the expected node is included in the rounded optimum set. The unrounded author data likely breaks this tie.
- 33-converter network source:
  - Reference [20] Appendix B Table B.II has now been transcribed. The derived collector-line reactance is `0.000130286 p.u.` for each adjacent 35 kV line segment using the paper's base values.
  - The imported edge list has 67 branches over 68 buses. Grounding the infinite bus gives a 67-by-67 network matrix with condition number about `4397.89`.
- 33-converter proposed placement:
  - paper: nodes `[42, 43, 44, 45, 53, 54, 55, 56, 65, 66, 67]`
  - reproduction report uses the same node set.
- Reported gSCR values are preserved for the 39-node and 33-converter comparison cases.

Reproduced qualitatively rather than EMT-identically:

- Fig. 6, Fig. 11, Fig. 12, and Fig. 14 time-domain responses are generated by a transparent MATLAB reduced-order response model with a smooth fault-period power sag and a post-fault PLL-mode oscillation. The curves reproduce the paper's stability trend:
  - no SE or low gSCR: weakly damped or divergent oscillation;
  - non-optimal SE placement: damping improves;
  - proposed SE placement: fastest convergence.
- A dedicated Simulink approximation is also available at `matlab/se_gfl_pll_small_signal_model.slx`. It is generated and simulated by `matlab/run_simulink_reproduction.m`, using a From Workspace voltage-sag input, a MIMO State-Space block for the PLL-dominated mode, and a To Workspace active-power output.
- The authors' original EMT/Simulink model is not provided in the PDF. Appendix Table IX is now transcribed from the supplied image, but exact EMT matching still requires unpublished implementation details such as limiters, initialization, and dq sign conventions. The reproduction therefore calibrates the fault-period sag and weakest mode to the reported `CgSCR`, `gSCR`, and damping ratios.

## Implementation Scope

The implemented scripts cover all numerical experiment sections in the paper:

- Single-converter infinite-bus eigenvalue trend, corresponding to Fig. 8.
- Modified IEEE 39-node gSCR/eigenvalue assessment, corresponding to Fig. 10 and Fig. 11.
- Modified IEEE 39-node SE placement comparison, corresponding to Table V and Fig. 12.
- 33-converter SE placement comparison, corresponding to Table VIII and Fig. 14.
- Two-area four-CBR illustrative placement, corresponding to Table I-III and Fig. 6.

## Important Limitation

This is now a data-backed reproduction of the paper's **gSCR method, placement logic, reported placements, reported stability ordering, scalar metrics, and imported network tables**. It is not a bit-for-bit reconstruction of the unpublished EMT model. To obtain EMT-identical waveforms, the remaining missing implementation details would be controller limiters, exact dq sign conventions, initialization procedure, and the authors' original Simulink/EMT block choices.
